# 素材来源与许可

本项目实际加载外部3D模型，全部必要文件在 `public/`，运行无须访问素材网站。

| 素材 | 作者 / 原始包 | 许可 | 实际使用 |
|---|---|---|---|
| 家具 | Kay Lousberg / KayKit Furniture Bits 1.0 | CC0-1.0 | 桌子、沙发、书架、仙人掌、灯、书籍、茶几，共8个模型 |
| 动物 | Quaternius / Ultimate Animated Animal Pack | CC0-1.0 | Fox、ShibaInu、Husky、Alpaca，保留Idle等动画 |
| 中文字体 | Google / Adobe，Noto Sans SC | OFL-1.1 | 使用字符子集，固定500字重，改名OfficeUISubset |
| 图标 | Twemoji，Twitter contributors / jdecked | CC-BY-4.0 | 动物头像、项目与事件SVG，原图未修改 |
| 渲染引擎 | Three.js authors | MIT | Three.js 0.186.1、GLTFLoader、SkeletonUtils、BufferGeometryUtils |

## 官方页面

- KayKit：https://kaylousberg.com/game-assets/furniture-bits
- 家具官方下载仓库：https://github.com/KayKit-Game-Assets/KayKit-Furniture-Bits-1.0
- Quaternius原始许可页面：https://quaternius.com/packs/ultimateanimatedanimals.html
- 动物字节获取镜像：https://github.com/agentkaerf/FreeModels ，仅选用上述原始CC0包。镜像不是素材作者。
- Noto：https://github.com/google/fonts/tree/main/ofl/notosanssc
- Twemoji：https://github.com/jdecked/twemoji
- Twemoji图形许可：https://creativecommons.org/licenses/by/4.0/
- Three.js：https://threejs.org/

## 署名

Twemoji graphics © Twitter contributors and Twemoji contributors, licensed under CC-BY 4.0. https://github.com/jdecked/twemoji . Graphics selected without modifications.

即使CC0不要求署名，仍感谢 Kay Lousberg 与 Quaternius。保留本文件和包内许可证，便于后续商业发行核查。字体子集可按OFL使用，修改版使用新名称OfficeUISubset。
