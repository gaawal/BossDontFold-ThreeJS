# v1.0 验证记录

- `npm run build`：生产构建通过，Three.js与资源均随包提供，无外部运行CDN。
- `npm test`：16项检查通过，包括完整四周调配后交付三个需求、阶段依赖、资格限制、培训、午休、请假、健康、Bug修复/回归、工资幂等、补交、奖励取消与存档。
- Chromium桌面：1440×1060，模型4种全部加载，家具全部加载，无页面异常、无资源404。
- Chromium手机视口：390×844，无横向溢出。仅模拟视口，不等同抖音客户端或真实手机硬件验证。
- 实际鼠标操作：从3D等待区拖员工到设计工位，资格符合后直接安排；错误岗位禁止工作。
- 实际UI操作：缺支付技能提示培训，培训8个有效工作小时后自动支援；保存、刷新后技能保留，游戏暂停。
- 激励奖励演示：取消不发奖，完成演示后恢复一次救急资金，保留员工与任务进度。
- 渲染：初始场景约47,546个三角形、105次主画面绘制调用。静态办公室几何已合批；性能数值只用于该测试场景，正式平台仍需真机验证。

开发测试使用的浏览器和下载缓存不包含在交付压缩包内。
