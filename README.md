# 老板，别倒闭！ — Three.js 3D 公司经营游戏 v1.3

固定办公室、设计/开发/测试工位，拖动合格员工安排任务，自动按人天工作。一局四周，第4周周五验收，周六可加班补交。

## 立即试玩

源码包已经包含构建好的 `dist/`，运行试玩**不需要下载 npm 依赖，也不依赖在线 CDN**。

- Windows：安装 Node.js 22.12 或以上，双击 `start-windows.bat`。
- macOS / Linux：安装 Node.js，运行 `./start.sh`。
- 或在项目目录执行 `node scripts/serve.mjs`，打开 http://localhost:8080 。
- 若已安装 Python，也可运行 `python -m http.server 8080 --directory dist`。
- 手机与电脑连接同一 Wi-Fi，在手机打开 `http://电脑局域网IP:8080`。防火墙需允许此端口。
- 不要直接双击 `dist/index.html`：浏览器的本地文件限制会阻止模型和模块加载。

## 开发

```bash
npm ci
npm run dev
npm test
npm run build
```

Vite 8 要求 Node.js 20.19+ 或22.12+；建议使用22.12或更新版本。`npm run build` 将完整网页、模型、字体和图标输出到 `dist/`。

## v1.3 手机布局

- 主玩法锁定在单个手机视口内，不再依赖整页纵向滚动。
- 需求卡改为横向滑动，保留完整名称、阶段、进度和风险信息。
- 3D办公室自动占据剩余空间，员工详情作为场景内浮层展示。
- 办公室改为居中正面镜头；全部动物头顶固定显示姓名、岗位和当前任务，待安排员工分两排展示，便于一一对应。
- 手机主界面按卡通经营手游重绘：经营状态卡、四周进度、三需求卡、木质办公室、员工操作卡和四项底部导航固定在同一视口。
- 底部“员工”打开独立调配抽屉；已验证 375×667、390×844、430×932 三种视口。

## 怎么玩

1. 周一早会结束前，选中一个需求。
2. 从办公室或员工列表拖动员工到对应工位；也可以选择员工后点击工位。
3. 合格员工拖到空工位立即工作；点击工位安排时可预览后确认。员工必须满足岗位、技术栈和级别要求。
4. 缺少技能时，安排培训；正常培训8个有效工作小时，午休/夜间/周日不计。可绑定培训后的自动支援任务。
5. 设计完成自动进入开发，开发完成进入测试。各个需求独立推进，可同时处于不同阶段。
6. 测试自动提Bug单。安排开发修复，再安排测试回归。严重Bug必须完成修复。
7. 周一、三、五自动暂停开早会，查看进度和动态调配。其他时间可临时暂停安排。
8. 9～18点为正常工作，12～13点午休；加班到20点。加班降低健康和精力并产生补贴，低健康增加生病请假的概率。
9. 每周日扣工资与房租。月底项目通过验收才收款，要留足现金。
10. 第4周周五18点验收；可安排周六补交，补交收入扣10%，另付补贴。

## 已实现

## 当前交付边界

这是可运行的 **Three.js浏览器游戏原型**，包含源码和生产构建，**不是可直接提交抖音审核的小游戏发行包**。当前UI使用DOM/CSS；抖音小游戏运行环境需Canvas UI、触摸与资源加载适配、生命周期/存储桥接、平台真机测试和正式广告位配置。

`src/platform.js` 已隔离激励广告接口，并包含 `tt.createRewardedVideoAd` 的完成回调处理；浏览器的奖励按钮明确为“模拟完整观看”，没有接入真实广告、也不产生广告收入。正式上架还需校验SDK行为、按平台规范展示广告标识，处理无填充与网络失败，并确保奖励幂等。

成长星目前为跨局保存的奖励记录；局外永久技能树尚未实现。局内公司升级树和员工成长分支已经可玩。初始三种需求为固定模板，局内随机性来自事件、缺陷和人员成长；后续可扩充随机需求池。

`docs/game-design.png` 是生成的美术概念图，真实游戏使用免费低多边形素材，精细度与概念图不同。当前免费动物包为四足角色，并非图中拟人服装角色；可在不修改模拟逻辑的情况下替换更精细的模型。

## 项目结构

- `src/game.js`：独立经营模拟，可在Node中测试。
- `src/office.js`：三维办公室、模型、动画、射线拖放和静态合批。
- `src/main.js`：中文界面、早会、分配、培训、档案与结算。
- `src/platform.js`：存档与激励奖励适配边界。
- `public/models/`：实际使用的KayKit家具、Quaternius动画动物。
- `public/fonts/`、`public/icons/`：本地字体与图标。
- `docs/`：设计图、玩法规则、素材来源及许可证。
- `tests/game.test.js`：经营逻辑回归检查。
- `dist/`：可直接通过HTTP服务器试玩的构建。

UI里的交付预测为当前排班的保守估算，未包含未来培训后新增人手、尚未发生的Bug和请假；最终结果以实际模拟为准。
